# Contributing to resistor

resistor is a personal project and part of Rosito Bench, created with care and dedication.
These are the guidelines for contributing.

## Bug Reports

Bug reports are always welcome. Please open an issue and include:
- A clear description of the problem
- A minimal example that reproduces the issue
- Your operating system and compiler version

## Bug Reports vs. Support

Bug reports are for problems with resistor code — not for general electronics help.
For general C++ help please use [Stack Overflow](https://stackoverflow.com/).

## Pull Requests

Pull requests for bug fixes are welcome. Enhancement PRs may be declined if they
take the project in a direction outside its original scope. This is not personal —
it is simply a matter of keeping the tool focused and maintainable.

If a PR is declined, you are always welcome to fork the repository.

## A Note

This tool was built with care, curiosity, and the satisfaction of understanding
how things work from the ground up. Treat it with the same respect.
